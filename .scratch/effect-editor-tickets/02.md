## Parent

#52 小程序：灯效编辑重构（快捷 / 自定义两档 + 术语重写）

## What to build

用户在设备详情页**不用懂任何协议概念**就能让灯亮起来。

打开设备详情页，看到一排成品效果卡：暖白常亮、呼吸、彩虹流动、流光追逐、冷蓝氛围、紫色氛围。点「呼吸」，整组灯珠立刻开始呼吸——不需要先选光区、不需要点应用。

选中某张卡后，卡片下方出现只属于它的参数：颜色、快慢（慢/中/快）、最暗（微亮/中暗/全暗）、尾长（短/中/长）、顺向/逆向、彩虹饱和度。拖动即生效，300ms 防抖后写入设备，没有「应用」按钮。

三处必须做对：

- **整组覆盖**：快捷档的语义是「整组变成这一个效果」，区间恒为整组全部灯珠、单层、叠加方式覆盖。
- **必须看得见**：如果当前有方案正在播放，固件会忽略实时光效区，用户点了却看不到变化。写入前先停止方案并明确提示「已停止方案，改为实时灯效」。
- **失败要如实**：写入被设备拒绝（链路异常、参数非法）时，重新读回设备真实状态刷新界面，并给出具体原因，绝不留下一个假的成功画面。

## Acceptance criteria

- [ ] 设备详情页出现 6 张效果卡，每张有名称、一行说明和颜色预览
- [ ] 点卡片后整组灯珠真的变成该效果（真机或模拟器实测，非仅改 UI 状态）
- [ ] 选中卡片的参数区只显示该卡支持的参数，其余不出现
- [ ] 调整任一参数后 300ms 内设备状态更新，无需点任何按钮
- [ ] 彩虹卡有饱和度滑杆，调低后彩虹明显变柔和
- [ ] 方案播放中点击卡片时自动停止方案，并提示已停止
- [ ] 写入失败后界面回到设备真实状态，并显示具体原因
- [ ] 多灯组设备可先选灯组，快捷档只作用于选中的那组
- [ ] 未连接时卡片区呈禁用态并给出可读提示
- [ ] 界面上不出现「毫秒」「0-255」「blend」等协议词
- [ ] 新增纯函数映射有单测；`tsc` 与 `vitest` 全绿；双主题下卡片文字可读
