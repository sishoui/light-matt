## Parent

#52 小程序：灯效编辑重构（快捷 / 自定义两档 + 术语重写）

## What to build

用户切到「自定义」档后，**能用一个漂亮的方式把灯组切成多个光区**，而不是手打数字。

灯组被画成一条可视化的灯珠条。用户在上面按住拖动，划出一段区间，实时显示「12–27」。已有光区用各自效果色标出，正在划的那段与已有光区相交时立刻变红——并且此时不会下发任何东西（本地就拦住，绝不发一帧必定被设备拒绝的配置）。

配几个省事的切分按钮：整条、前半、后半、平均切 2 / 3 / 4 段。点一下就直接得到对应的光区划分，用户可以在此基础上改。

每个光区可以选主效果（四种灯效之一）并调它的参数。改动同样即时生效：拖动区间或换效果后短暂防抖就写入设备，用户马上看到这一段灯变了。

必须先做成的前提：这一票只处理「一个步骤内的多个光区」。时间轴（多个步骤）留给下一张票。

## Acceptance criteria

- [ ] 自定义档能看到灯珠条，每颗灯珠一格，未覆盖的灯珠呈熄灭样式
- [ ] 在灯珠条上拖动可划出区间，松手后显示起止编号
- [ ] 划出的区间与已有光区重叠时立即变红，且不写入设备
- [ ] 整条 / 前半 / 后半 / 均分 2 / 3 / 4 六个快捷切分按钮都产生正确且互不重叠的区间
- [ ] 每个光区可选四种主效果之一，选中后该段灯真的变化
- [ ] 光区数量达到 8 个上限时有明确提示且不能继续新增
- [ ] 删除光区需二次确认，确认后该段熄灭且其余光区不受影响
- [ ] 修改任一光区区间后，其余光区的区间不会被意外改动
- [ ] 数字精修入口（直接输入起止）仍然可用，非法输入就地提示
- [ ] 未连接或灯珠数未知时控件禁用并给出可读提示
- [ ] 布局与校验纯函数有单测；`tsc` 与 `vitest` 全绿；双主题下灯珠条与文字可读
