## Parent

#52 小程序：灯效编辑重构（快捷 / 自定义两档 + 术语重写）

## What to build

用户在「快捷」和「自定义」之间来回切换时，**辛苦编排的东西不会丢**。

场景：用户花十分钟在自定义档搭了一套多光区、多步骤的方案，想切到快捷档看一眼暖白常亮，然后切回自定义——此时编排必须还在，并提示「已恢复你之前的编排」。

实现要点：

- 切到快捷档**之前**，把当前灯组的完整编排（光区、当前方案槽位、当前步骤位置）保存为内存快照。
- 切回自定义档时自动恢复，不弹窗询问（反复切换时弹窗会变成骚扰）。
- 快照按「设备 + 灯组」隔离：连过两台灯控、或同一台的不同灯组，快照不串号。
- 快照**只在内存**，不落存储：刷新小程序后回到设备真实状态是符合预期的，避免「上次的编排无限期占着存储」与「恢复出的配置与设备当前状态不一致」。
- 已经是快捷档再点快捷，不要保存快照——否则会用快捷档的整组配置覆盖掉真正的编排。

## Acceptance criteria

- [ ] 自定义档搭好编排 → 切到快捷档 → 切回自定义档，编排完整恢复
- [ ] 恢复时有「已恢复你之前的编排」提示
- [ ] 第一次进入自定义档（从未切过）时不提示恢复，直接是空白编排
- [ ] 在快捷档调整过参数后切回自定义，仍然恢复到之前的编排（不被快捷档覆盖）
- [ ] 两台不同设备的快照互不影响
- [ ] 同一设备的不同灯组快照互不影响
- [ ] 刷新小程序后快照清空，界面回到设备真实状态
- [ ] 快照逻辑纯函数有单测（含深拷贝隔离、按设备/灯组隔离、重复保存覆盖）
- [ ] `tsc` 与 `vitest` 全绿
