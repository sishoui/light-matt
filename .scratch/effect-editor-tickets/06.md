## Parent

#52 小程序：灯效编辑重构（快捷 / 自定义两档 + 术语重写）

## What to build

把前四张票做完的界面**统一到模玩灯控的语言**，并清掉所有旧的、重复的入口。

三件事：

**一、术语替换（用户可见文案，代码标识不动）**

灯控 / 灯组 N / 光区（从 1 编号）/ 主效果 / 叠加效果 / 叠加方式 / 步骤 / 灯效方案 / 写入灯控 / 启用这套方案 / 快捷 / 自定义。

同时修掉三处现存的具体错误：

- 剧本页脚注写着「段参数在『灯光 / 段编辑』页设置」——**「灯光页」根本不存在**。
- 校验文案里的「层 1 / 层 2」与界面的「第 1 层 / 第 2 层」含义相反。
- 灯效编辑提示里把英文 `blend` 暴露给用户。

**二、删除旧入口**

- 删除「剧本」tab，底部只留「设备 / 发现」两项，并调整图标间距使视觉不空。
- 删除段编辑页及其路由；相关测试与自动化脚本同步清理。

**三、设备控制页收窄**

只保留：电源、亮度、各灯组开关、一行「当前灯效」摘要（如「呼吸 · 暖白」或「方案 2 · 步骤 3 / 5 · 播放中」）。段列表、色环、颜色预设全部移除。点摘要进入对应模式编辑。

## Acceptance criteria

- [ ] 底部只有「设备 / 发现」两个 tab，两项布局不显空旷
- [ ] 界面上不再出现：段（作为光区含义）、第 1 层 / 第 2 层、混合方式、blend、阶段、剧本、下发、激活
- [ ] 编号全部从 1 开始，不再出现「段 0」
- [ ] 不再出现「灯光页」这类指向不存在页面的文案
- [ ] 段编辑页已删除，路由表与引用同步清理，无残留死代码
- [ ] 设备页只剩电源、亮度、灯组开关与一行当前灯效摘要
- [ ] 点当前灯效摘要能进入对应模式的编辑
- [ ] 所有页面在浅色与深色主题下文字可读（`theme.test.ts` 通过）
- [ ] `tsc` 干净、`vitest` 全绿、事件绑定核验无缺失
- [ ] 模拟器自动化脚本更新到新结构并通过（快捷卡生效、模式切换恢复、写入失败回滚）
- [ ] 双主题截图归档到证据目录
