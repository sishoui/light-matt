# 03：灯带点亮与电气基线

**要构建什么**：在最真实的硬件上（ESP32-C3 开发板 + 30 灯珠 WS2812B）用 `led_strip` 的 RMT backend 把灯带稳定点亮，并留下后续所有渲染工作的电气基线。

必须确认：组件能拉取并编译、30 灯珠全红/全绿/全蓝的实际颜色与通道顺序（GRB 假设是否成立）、低亮度与中亮度的表现、有无闪烁或首灯错色、全白高亮度时的供电表现（是否掉压/重启）。同时写清接线：数据脚、5V 供电、共地、首灯电容、数据线串阻、电平转换要求。

**阻塞于**：02（没有工具链什么都烧不进去）

**状态**：ready-for-agent

- [ ] 30 灯珠全亮，颜色均匀，无尾部衰减
- [ ] 纯红/纯绿/纯蓝三帧的实际颜色与命令一致，或明确记录需要交换哪两个通道
- [ ] 连续点亮 5 分钟无闪烁、无重启
- [ ] 全白高亮度的实测结果记录在案（是否掉压 / 重启 / 是否必须限亮度）
- [ ] 接线说明写清共地、电容、串阻与电平转换要求
- [ ] 明确记录默认数据脚，并对照 C3FH4 的禁用引脚清单确认它可用

> 本票与 wayfinder 地图的【led_strip 点灯验证】重合。3.3V 驱动 5V 灯带在规格上不达标是已知前提，本票不是去证明它没问题，而是记录它在这块板上的实际表现。
