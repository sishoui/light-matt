# 09：颜色与预设端到端

**要构建什么**：一条完整的颜色路径。色环取色（HSV）→ 用户空间 RGB → BLE 写入 → 固件 gamma + 亮度 → 灯带显示正确颜色；再加一排 6-8 个预设色块，点击即用「一次设全部」下发。

这一票同时验证「一次设全部」的原子感：开关、亮度、RGB 在一条帧里下发，灯带不出现可感知的中间态。低亮度下的色相正确性也在这一票验收。

**阻塞于**：08（亮度链路与 gamma 已就位）

**状态**：ready-for-agent

- [ ] 色环选色后灯带颜色正确、无明显偏色
- [ ] 预设色块点击即生效
- [ ] 「一次设全部」（开关 + 亮度 + RGB）在 14 字节预算内，且无中间态跳变
- [ ] 低亮度下色相仍然正确
- [ ] 颜色命令的测试向量在两端通过
- [ ] 开关与颜色快速切换时不出现旧色回跳
- [ ] 色环在小屏上的触控精度达到可用

> 预设色块只是「一次设全部」的快捷入口，不引入新的协议命令。
