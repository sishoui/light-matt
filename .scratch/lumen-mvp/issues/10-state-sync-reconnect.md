# 10：状态同步与断线回连

**要构建什么**：让界面和设备在任何时候都以设备为准。连上后读 State 特征值同步全部控件；断线立即反映到 UI；自动按 1s/2s/4s 退避回连；进前台静默回连；回连后重新订阅 notify 并再次读 State。

同时落实错误分诊：`10006` 走重连、不重试写；退避耗尽后显示「未连接」并给手动重连入口；设备侧旧连接必须释放，避免单连接配置下重连一直失败。

**阻塞于**：09（State 里的颜色/亮度/开关都要已经实现，同步才有意义）

**状态**：ready-for-agent

- [ ] 设备断电 → UI 立即显示未连接
- [ ] 设备上电 → 按退避节奏自动回连，UI 状态与设备一致
- [ ] 退避耗尽后显示未连接并给手动重连入口，不无限循环
- [ ] 回连后 notify 仍能收到 ACK（重新订阅生效）
- [ ] `10006` 不触发写重试，`10008` 加间隔重试一次，`10001` 非致命等待
- [ ] State 是权威：UI 不用本地缓存覆盖设备
- [ ] 进前台静默回连不打断正在进行的扫描/手动连接

> 这一票不新增协议命令，只把已有的 State 与连接生命周期用对。
