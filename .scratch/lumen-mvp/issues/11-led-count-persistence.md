# 11：灯珠数量与断电记忆

**要构建什么**：两条与「设备记得住」有关的能力。

灯珠数量：小程序里能改，改完立即生效，重启后保持；固件重建 `led_strip` 句柄，失败回滚并保留旧配置；非法值（0 / 超上限 / 非数字）明确拒绝。

断电记忆：颜色、亮度、开关状态变更后 debounce 写 NVS，上电恢复；恢复失败回默认值；拖滑块不逐像素写 flash。首次上电的默认状态必须安全、可预期。

**阻塞于**：09（颜色/亮度/开关的状态字段都已存在）

**状态**：ready-for-agent

- [ ] 改灯珠数量立即生效，重启后保持
- [ ] 非法灯珠数量被拒绝且保留旧值
- [ ] 断电重启恢复颜色、亮度、开关
- [ ] 状态变更使用短 debounce，拖动滑块不逐像素写 flash
- [ ] NVS 写失败按协议规定回结果码，不静默吞掉
- [ ] 首次上电（无历史状态）落在协议规定的默认状态
- [ ] 重启后读 State 与 UI 显示一致

> 灯珠数量是设备级低频设置，放在连接/设备弹层内，不占主控制流。
