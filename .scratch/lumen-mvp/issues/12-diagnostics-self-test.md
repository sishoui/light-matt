# 12：协议日志与自检

**要构建什么**：让真机上的问题可以被看见。

小程序侧：一个环形缓冲保留最近 200 帧，记录时间戳、方向、hex、解析后的命令名与参数；页面上有隐藏的协议日志面板（连点版本号 5 次开启），支持暂停、清空、复制。开发版同时把每帧 hex 打到 console。

固件侧：串口按帧打印命令字、seq、结果码；提供一个自检命令，不依赖小程序就能按固定顺序点亮颜色，用于验证接线与通道顺序。

**阻塞于**：09（所有命令都已实现，日志才有完整的解析结果）

**状态**：ready-for-agent

- [ ] 每一帧都能在面板看到时间戳 / 方向 / hex / 解析结果
- [ ] 面板的暂停、清空、复制都可用
- [ ] 日志按 seq 能与固件串口对齐
- [ ] 自检命令不依赖小程序即可验证灯带与通道顺序
- [ ] 日志缓冲有上限，不无限增长
- [ ] 开发版 console 与面板看到的是同一份数据

> 诊断不是产品化打磨，是验收与排查的必要工具；这一票的边界到此为止，不做日志导出文件或远程上传。
