## Parent

#71（规格：灯组进阶编辑器打磨）

## What to build

新增一条命令，让「删除一套方案」能真的从设备上删掉，而不是只删本机草稿。

命令字取原保留区里的 `0x1E`，载荷 1 字节 `script_id`。语义：清空该 id 的已提交剧本（阶段数归零、所有段置空）；若它正是当前激活的剧本，则退回「无激活剧本」并停止播放。对一个本来就没提交过的 id 视为成功（幂等），不报错。id 越界回参数非法；写入持久化失败回存储失败并保留原内容。

**不改协议版本号**：v4 不变，旧固件收到 `0x1E` 按未知命令拒绝，不会误改任何东西。协议文档的保留区说明、命令表、校验规则同步更新，两代向量补上用例。

## Acceptance criteria

- [ ] 发一条清空命令后，该编号的剧本在设备上确实没了（阶段数回 0，摘要显示空白）
- [ ] 清空正在播放的那套方案时，播放停止且设备回到「无激活剧本」
- [ ] 清空一个本来就没有内容的编号视为成功，不报错
- [ ] 编号越界被拒绝并回参数非法
- [ ] 持久化失败时回存储失败，原剧本内容保持可用
- [ ] 其它编号的剧本完全不受影响
- [ ] 协议文档写明新命令的命令字、载荷、语义、在「未提交即成功」上的幂等规则，以及「不改版本号」的原因
- [ ] 旧版本固件收到该命令按未知命令拒绝，且能继续正常服务后续帧
- [ ] 两代测试向量补充清空命令的用例，三端校验一致
- [ ] 固件 host 单测覆盖：正常清空、清空激活剧本、幂等、越界、持久化失败
- [ ] 固件 host 单测与类型检查全部干净
