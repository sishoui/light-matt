## Parent

#71（规格：灯组进阶编辑器打磨）

## What to build

新增三种灯效，让编排里能有爆闪、心跳，以及一个显式的「这里就是黑的」。

层编码的**宽度不变**（v3 八字节 / v4 九字节），新类型沿用现有七字节参数块，所以帧长、状态存储、报告帧全都不变，协议版本号也不变。

三种类型的参数语义：

- **爆闪**（`0x04`）：色相、饱和度、周期、占空比、保留位。周期即一次完整闪烁，**下限 100 毫秒**（对应约 10Hz 的上界），`0` 表示静止不出光。占空比表示亮的时间占比，界面上给窄 / 中 / 宽三档。包络用方波，两端留一小段线性斜坡避免硬切。
- **心跳**（`0x05`）：色相、饱和度、周期、脉冲宽度、标志位。一个周期内出现一大一小两次短脉冲，其余时间在谷底。周期**下限 500 毫秒、上限 1500 毫秒**（对应 40–120 BPM），`0` 表示静止。
- **熄灭**（`0x06`）：所有参数恒为 0，永不发光。它与「不画光区」的区别是**在时间轴与光区轴上可见**，用户能明确表达「这一段就是黑的」。

频率上界的老实话必须写进文档：固件默认 20fps，每帧 50 毫秒，10Hz 已经是能表现的上界；**本次不提高帧率**，因为八条满 100 颗时提高帧率会掉帧，那种掉帧比低频更糟。

校验规则要跟着加：新类型各自的周期下限、保留位必须为 0、熄灭层参数全零、空层仍是 `0xFF` 且不能被当作主效果。

## Acceptance criteria

- [ ] 爆闪在真机上按设定频率与占空比闪烁，改频率与占空比立刻看得出差别
- [ ] 爆闪周期低于 100 毫秒被拒绝并回参数非法
- [ ] 心跳在真机上呈现「一大一小」双脉冲，节奏随周期在 40–120 BPM 间变化
- [ ] 心跳周期超出 500–1500 毫秒被拒绝
- [ ] 熄灭层在真机上完全不发光，且不影响同一条灯组上其它光区
- [ ] 三种类型都能作为叠加层与主效果使用（熄灭作为叠加层的行为在下一张票里另行约束）
- [ ] 三种类型的保留位非 0 时被拒绝
- [ ] 旧版本固件收到新类型时按未知类型拒绝，不静默降级成别的效果
- [ ] 效果规格文档补充三种类型的参数表与语义
- [ ] 两代测试向量补充新类型的编码用例，三端校验一致
- [ ] 固件 host 单测覆盖三种类型的零档 / 中间档 / 满档输出，以及各自的边界拒绝
- [ ] 固件 host 单测与类型检查全部干净
