## Parent

#71（规格：灯组进阶编辑器打磨）

## What to build

进阶档的效果类型行从四种扩到七种，并让每种类型只显示自己用得上的旋钮。

新增三类在类型行里排在原四种之后：**爆闪**、**心跳**、**熄灭**。参数区按类型整体替换——用户永远看不到当前类型用不上的控件。

各类型的参数：

- 静态：色相、饱和度、亮度
- 呼吸：色相、饱和度、亮度、周期、最低亮、波形
- 彩虹：周期、跨度、方向
- 流光：色相、饱和度、亮度、周期、尾长、方向
- 爆闪：色相、饱和度、频率、占空比（窄 / 中 / 宽）、亮度
- 心跳：色相、饱和度、节奏（BPM）、亮度
- 熄灭：只有亮度且固定在最低——实际上下发时是全零参数，界面上给出「这一段不亮」的说明而不是一堆无效旋钮

**叠加层可选类型不含熄灭**：叠加一个「熄灭」等于什么都没做，只会让人困惑。叠加层可选静态 / 呼吸 / 彩虹 / 流光 / 爆闪 / 心跳。

界面词表照旧不出现协议词（毫秒、段、阶段、剧本、下发、激活、第几层）。频率用赫兹、节奏用 BPM、周期用秒。

## Acceptance criteria

- [ ] 效果类型行有七个等宽按钮，新增的爆闪 / 心跳 / 熄灭都在
- [ ] 切换类型后参数区整体替换，不出现当前类型用不上的旋钮
- [ ] 爆闪有频率与占空比两个专属控件，频率上限对应 10Hz
- [ ] 心跳有节奏一个专属控件，范围对应 40–120 BPM
- [ ] 熄灭不显示颜色与周期控件，只说明这一段不亮
- [ ] 叠加层的类型选择里有爆闪与心跳，没有熄灭
- [ ] 切换类型时颜色保留，其余参数按新类型语义重置
- [ ] 新类型的值在本地预检时就拦住越界（频率过快、节奏过快或过慢），不发帧
- [ ] 拖控件过程中只更新草稿与预览，松手才提交
- [ ] 界面上不出现协议词
- [ ] 单元测试覆盖：七类型列表、按类型整体替换、各类型参数键、叠加层不含熄灭、越界拒绝
- [ ] 渲染层回归覆盖：切类型后参数区真的整体替换、新类型能写入并看出变化
- [ ] 固件 host 单测、小程序单测与类型检查全部干净
