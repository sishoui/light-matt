## Parent

#71（规格：灯组进阶编辑器打磨）

## What to build

简单档的成品效果卡从六张扩到九张，改成三列网格，让新灯效在不动进阶档的情况下也能一键用上。

原有六张保留不动：暖白常亮、呼吸、彩虹流动、流光追逐、冷蓝氛围、紫色氛围。新增三张：

- **爆闪白**：白色爆闪，中等频率、中等占空比
- **心跳暖红**：暖红心跳，约 60 BPM
- **熄灭黑**：整组不亮

语义仍是**整组覆盖**：点一张卡就让这条灯组整体变成该效果，写入前必须先清掉这组的其它光区，否则设备会以参数非法拒绝，用户点了卡却毫无变化。

点「熄灭黑」与其他卡的区别只在结果：整组黑掉，但这条灯组自身仍然开着（不是关掉灯组）。从设备读回时，能反推出「当前是熄灭卡」——整组一个光区、主效果是熄灭、无叠加层。

卡片两列改三列后，卡片内文字仍要读得清：名称一行、提示一行，超出截断不换行。

## Acceptance criteria

- [ ] 简单档显示九张卡，排成三列
- [ ] 点「爆闪白」后这条灯组整体爆闪，不是只改界面数据
- [ ] 点「心跳暖红」后整组呈现心跳，节奏为设定的默认值
- [ ] 点「熄灭黑」后整组不亮，但该灯组在设备上仍是开启状态
- [ ] 多光区灯组上点任意新卡都不会因为光区重叠被设备拒绝（写入前清掉其它光区）
- [ ] 卡片名称与提示在三列宽度下不溢出、不换行
- [ ] 从设备读回时能正确反推出当前是九张卡中的哪一张
- [ ] 界面词表照旧不出现协议词
- [ ] 单元测试覆盖：九张卡的定义、新卡反推、三列布局的数量断言
- [ ] 渲染层回归覆盖：九张卡渲染、点新卡后设备状态真的变
- [ ] 固件 host 单测、小程序单测与类型检查全部干净
