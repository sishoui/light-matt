## Parent

#71（规格：灯组进阶编辑器打磨）

## What to build

让时间轴**永远完整铺在一屏里**，不再因为步骤多或时长碎而横向滚动。

总宽恒等于容器宽度。块宽按各步骤时长比例分配，但每块有**最小宽度下限**（24px），保证极短步骤也点得中。下限放不下时先压缩块与块之间的间隙（8px 降到 4px），还放不下就退化为均分——任何分布下都不出容器、每块都有宽度。

块宽不足一定值（48px）时不渲染时长文字，只保留序号，时长看下方数值行，避免文字溢出压到邻块上。

现有的「撑宽 + 横向滚动」整套逻辑要删掉，包括滚动开关、撑宽上限、以及为撑宽服务的那段行宽计算。块宽度以像素内联，保证「算出来的宽度」与「显示宽度」是同一份真相。

## Acceptance criteria

- [ ] 八个步骤并列时时间轴总宽不超过容器，不出现横向滚动
- [ ] 八个步骤一起排时每块都还能点中
- [ ] 极短步骤（最小时长）的块宽不低于下限
- [ ] 块宽不足阈值时不显示时长文字，序号仍可见
- [ ] 步骤数从一变到八，时间轴始终铺满容器且不溢出
- [ ] 时长改变后块宽实时跟着变，不重建整页
- [ ] 点任一断切换当前步骤，下方时长与光区跟着切换
- [ ] 缩略色带仍按该步骤各光区的灯珠比例绘制，不因固定宽度而错位
- [ ] 单元测试覆盖：比例分配、下限钉住后的比例语义、间隙降级、均分兜底、单步与八步、极端时长分布不出容器、窄块不出文字
- [ ] 渲染层回归覆盖：时间轴总宽不超过容器、无横向滚动
- [ ] 固件 host 单测、小程序单测与类型检查全部干净
