## Parent

#71（规格：灯组进阶编辑器打磨）

## What to build

让长按拖拽换顺序有真正的物理反馈：块抬起来、跟着手指走、其它块给它让位。

长按阈值收紧到 300 毫秒后进入拖动。被拖的块**抬起**：略微放大、投上一层阴影、层级抬高，并跟随手指横向移动。原位置到落点之间的块整体平移一个块宽，让出插槽，过渡平滑；落点块高亮描边。松手提交顺序并回弹到最终位置。

位移量必须由纯函数算出，页面不做算术——否则「看到的位移」和「实际的落点」会成为两套真相。全部用位移变换实现，不改布局属性（小程序里布局重排动画不稳定）。拖动结束后要抑制紧随其后的那次点击，否则顺序会因为手指抬起而跳一下。

## Acceptance criteria

- [ ] 长按约 300 毫秒后块抬起，有明显的高起与阴影
- [ ] 拖动时被拖的块跟着手指横向移动
- [ ] 拖动时其它块整体平移让出插槽，落点块高亮
- [ ] 松手后顺序真的改变，当前选中步骤跟着走
- [ ] 拖动结束后不会误触发一次点击
- [ ] 拖到自身位置或边界外时不产生顺序变化，块正常回弹
- [ ] 拖动过程中时间轴不出现横向滚动
- [ ] 单元测试覆盖：位移映射（向左、向右、原地、越界）、重排后选中项跟随、拖动后的点击抑制
- [ ] 渲染层回归覆盖：拖动过程中有位移样式、松手后顺序真的变了
- [ ] 固件 host 单测、小程序单测与类型检查全部干净
