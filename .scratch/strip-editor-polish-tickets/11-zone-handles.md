## Parent

#71（规格：灯组进阶编辑器打磨）

## What to build

让光区轴上的「这一段的起止在哪」一眼可见。

选中一个光区时，块上除了主题色描边，**两端各画一个圆形手柄**——手柄高于条带、能明确指示「起点在这一端」「终点在这一端」，且不改变块本身的宽度，避免选中后位置跳动。轴下方显示这一段的区间文案，例如「第 0–19 颗 · 20 颗」，让用户能用数字核对，而不只是看颜色。

未被任何光区覆盖的区间仍画成灰条、点不动；零光区时轴给出引导而不是一片空白。

## Acceptance criteria

- [ ] 选中光区后，块上出现主题色描边
- [ ] 选中光区的两端各有一个明显的圆形手柄，高于条带
- [ ] 手柄不改变块宽度，选中前后块的位置不跳动
- [ ] 轴下方显示「第 x–y 颗 · n 颗」，数值与设备上实际区间一致
- [ ] 未覆盖区间仍是灰条且点不动
- [ ] 零光区时给出引导文案而不是空白
- [ ] 整条覆盖时起止手柄分别落在两端，文案显示完整区间
- [ ] 单颗光区时两端手柄不重叠到看不清
- [ ] 单元测试覆盖：手柄位置（普通区间、单颗、整条、零光区）、区间文案、灰条区间列表
- [ ] 渲染层回归覆盖：选中后手柄与文案出现
- [ ] 固件 host 单测、小程序单测与类型检查全部干净
