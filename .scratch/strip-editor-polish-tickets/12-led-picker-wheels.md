## Parent

#71（规格：灯组进阶编辑器打磨）

## What to build

在选灯珠的弹窗里补上「用数字直接选起止」，并让起点与终点在格子上看得出来。

**起止样式**：起点格是实心圆点加粗数字，终点格是空心圆环，区间内的格子填半透明主题底色。已被其它光区占用的格子置灰、点不动，只留一个小色点说明归属。

**两个数字滚轮**：弹窗底部放起点与终点两个滚轮。滚轮的值域**只包含与当前锚点连通的那一段连续空闲灯珠**——被别的光区占着的序号根本不出现在滚轮里，所以用户不可能选出非法区间。起点滚轮取「连续空闲段的左端到锚点」，终点滚轮取「锚点到右端」；锚点还没定时起点滚轮给出整段空闲、终点滚轮不可用。显示按第 1 颗起算，内部仍用 0 基。

任一端一改，网格立刻预览；区间无效时「确定」不可用。点同一颗两次仍视为取消，不产生只含一颗灯珠的光区。

## Acceptance criteria

- [ ] 弹窗里起点格是实心圆点加粗数字，终点格是空心圆环
- [ ] 区间内的格子有半透明主题底色，确认所选范围
- [ ] 底部有起点与终点两个数字滚轮，拖动即可选值
- [ ] 滚轮里不出现被其它光区占用的序号
- [ ] 起点滚轮只给出锚点左侧的连续空闲，终点只给出右侧的连续空闲
- [ ] 锚点未定时终点滚轮不可用
- [ ] 改任一端后网格立刻预览，区间无效时「确定」不可用
- [ ] 被别的光区占用的格子置灰且点不动
- [ ] 点同一颗两次视为取消，不产生单颗光区
- [ ] 滚轮显示从第 1 颗起算，与格子上的编号一致
- [ ] 单元测试覆盖：连续空闲段计算（左端、右端、两侧都被占、整条空闲、零空闲）、锚点未定、任一端变更后的区间合法性与确定可用性
- [ ] 渲染层回归覆盖：被占用格点不动、滚轮里不出现被占序号
- [ ] 固件 host 单测、小程序单测与类型检查全部干净
