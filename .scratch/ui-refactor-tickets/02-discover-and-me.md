# 02: 发现页 + 我的页

## Parent

#60

## What to build

发现页缩成一个扫描入口，设置项整体搬到「我的」。

**发现页**（二级页）：只有一个扫描 / 停止按钮、一行连接状态、一个扫描结果列表。结果列表里已有的设备带「已知」标记，点一行就连上并回到设备页。页面上不再有「我的设备」列表、没有外观、没有演示开关、没有版本号。

**我的页**（tab 2）：从上到下一段一段填满——

- 头像与昵称：头像用微信的头像选择能力，昵称用昵称输入框，两者只写本机存储；默认昵称「微信用户」，默认头像是纯 CSS 占位。不调用已下线的获取用户信息接口。
- 外观：浅色 / 深色 / 跟随系统三选一，切换后立即生效，tabBar 也跟着换。
- 演示设备：开关，附一句说明「没有真机记录时默认开启」。
- 我的设备：列出有记录的设备，可删除；每行显示名称与最近使用时间。
- 页脚：版本号；连点 5 次打开协议日志面板（暂停 / 清空 / 复制 / 关闭，与现有能力一致）。

旧的发现页在搬家完成后删除。

## Acceptance criteria

- [ ] 发现页只有一个扫描按钮 + 一行状态 + 结果列表，扫到的设备能点进去连上
- [ ] 发现页上不存在外观、演示设备、我的设备管理、版本号、协议日志入口
- [ ] 我的页能显示头像与昵称，改完退出重进仍然保留（只存本机）
- [ ] 我的页切换外观后立即生效，且切到二级页再回来仍是所选主题
- [ ] 我的页能开关演示设备，关掉后设备页不再出现占位设备
- [ ] 我的页能删除一台设备，删除后设备页不再出现它
- [ ] 我的页版本号连点 5 次能打开协议日志，面板能关闭、能复制
- [ ] 旧的发现页已从页面列表与路由常量中移除，代码里不再有指向它的跳转
- [ ] 交互回归脚本覆盖：菜单能开、我的页每个设置项点得动、发现页能扫描
- [ ] 类型检查、全部单元测试、渲染层回归脚本全部干净
