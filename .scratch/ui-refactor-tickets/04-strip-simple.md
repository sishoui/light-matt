# 04: 灯组页 · 简单档

## Parent

#60

## What to build

新建灯组详情页，并把现有的成品效果卡搬过来，让用户从设备页的灯组卡片点进来就能改这一条灯组的灯效。

**页面结构**：顶部是灯组名称与「方案 ①」按钮（点一下在四个方案槽位之间轮换，空槽位标注为空白）；下面是「简单 / 进阶」分段控件，默认停在简单档。

**简单档**：六张成品效果卡（常亮 / 呼吸 / 彩虹 / 流光 / 闪烁 / 警灯），点一张就让整组统一变成该效果；下面固定三项参数：色相、饱和度、亮度，全部是滑块。底部唯一的按钮是「应用并播放」。

语义仍是整组覆盖：写入前必须先清掉这条灯组的其它光区，否则设备会以参数非法拒绝，用户点了卡片却毫无变化。

进阶档这一票只显示「即将可用」的占位，真正的编辑器在后续票里实现。

## Acceptance criteria

- [ ] 从设备页的灯组卡片能进入该灯组详情页，顶部显示正确的灯组名与灯珠数
- [ ] 简单档显示六张效果卡，点一张后设备上这条灯组真的变成该效果（不是只改界面数据）
- [ ] 简单档的颜色/饱和度/亮度滑块能真实下发，改完立刻可见
- [ ] 多光区灯组上点效果卡不会因为光区重叠被设备拒绝（写入前清掉其它光区）
- [ ] 顶部方案按钮能在四个槽位间轮换，空槽位有明确标注
- [ ] 简单 / 进阶切换后内容整体替换，切回来状态保留
- [ ] 「应用并播放」在有未写入改动时能一步完成写入与播放
- [ ] 界面上不出现协议词（毫秒 / 段 / 阶段 / 剧本 / 下发 / 激活）
- [ ] 灯效编辑回归脚本改为面向灯组页验证效果卡生效与参数区
- [ ] 类型检查、全部单元测试、渲染层回归脚本全部干净
