## What to build

进阶档的第一层：时间轴与时长。

**时间轴**：每一段是一个块，宽度按这一段的时长占比分配，同时给一个最小宽度保底，让零点几秒的段在多段并列时仍然点得到。点一个块就选中它；长按约零点几秒进入拖动状态，横向拖到别的块上就交换顺序，松手结束。右上角「+ 加一段」新建一个默认时长、没有光区的段并选中它，上限八段。每个块内部用该段光区的颜色按比例铺成一条缩略色带。

**时长**：时间轴下方一条拖拽条，范围零点五秒到三十秒，最小单位零点五秒，下方三档刻度。拖动时时间轴的块宽实时变化，不重建整页。

这一票只做时间轴与时长；光区仍是占位，效果参数沿用简单档的控件。

时间轴的比例计算、时长钳位与重排规则做成独立的纯逻辑模块并单测——这部分规则如果只靠模拟器看，边界（单段、八段、最短时长）会漏。

## Acceptance criteria

- [ ] 时间轴按各段时长比例分配宽度，最短的段在八段并列时仍然可以点击
- [ ] 点时间轴的任一断切换当前段，下方的时长与光区跟着切换
- [ ] 长按后拖动可以把一段移到别的位置，松手后顺序真的改变，且当前选中段跟着走
- [ ] 「+ 加一段」新增一个空段并选中它；达到八段后按钮不可用
- [ ] 拖动时长条能改变当前段的时长，时间轴块宽同步变化，最小单位是零点五秒
- [ ] 时长在零点五到三十秒之外无法设置
- [ ] 时间轴块的缩略色带按该段光区的灯珠比例绘制
- [ ] 时间轴纯逻辑模块有单测覆盖：时长钳位、比例分配、最小宽度下的比例语义、按索引重排、八段上限、越界与自身拖动
- [ ] 单测直接构造输入断言输出，不经过页面与 wx 接口
- [ ] 类型检查、全部单元测试、渲染层回归脚本全部干净
