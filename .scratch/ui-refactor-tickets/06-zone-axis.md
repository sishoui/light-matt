# 06: 进阶档 · 光区轴与灯珠弹窗

## Parent

#60

## What to build

进阶档的第二层：光区分段轴与灯珠弹窗。

**光区轴**：与时间轴同一套视觉，但按灯珠下标比例定位。每个光区是一块，未被任何光区覆盖的区间画成灰条，让「还有暗区」一眼可见。点一块选中它，选中态用描边而不是改变颜色，避免和光区自身的颜色混淆。右上角「+ 新增」用于新增，上限八个光区。

**灯珠弹窗**：灯珠格子不进主界面，只在新增或修改范围时弹出。一次渲染该灯组全部灯珠（有几颗画几颗），按网格排列。第一次点击设锚点，第二次点击确定区间并自动取两端之间的全部灯珠；属于其它光区的格子置灰且点不动；与其它光区重叠时当场显示错误并保留弹窗、不写草稿；同一颗点两次视为取消，不产生只含一颗灯珠的光区。弹窗底部三个动作：确定、删除（仅对已有光区可用）、取消。

多灯组语义：只编辑当前灯组在这一步的那一片，其它灯组原样保留，写入时按「当前步骤 × 当前灯组」替换而不是整体覆盖。

光区轴的布局计算、未覆盖区间与重叠判定做成独立纯逻辑模块并单测。

## Acceptance criteria

- [ ] 光区轴按灯珠比例定位每个光区，未覆盖区间显示为灰条
- [ ] 点光区轴上的块能选中该光区，选中态与光区颜色可区分
- [ ] 「+ 新增」打开弹窗，弹窗里按该灯组真实灯珠数渲染格子
- [ ] 弹窗里点第一颗再点第二颗能选出区间，顺序颠倒也能得到正确区间
- [ ] 弹窗里属于其它光区的格子置灰且点击无效
- [ ] 弹窗里划出与其它光区重叠的区间时当场报错，不确定、不落草稿
- [ ] 弹窗里同一颗灯珠点两次不会产生只含一颗灯珠的光区
- [ ] 弹窗能修改已有光区的范围、能删除光区、能取消且不生效
- [ ] 达到八个光区后「+ 新增」不可用
- [ ] 在别的灯组上编辑不会改动当前灯组的光区，写入后其它灯组保持原样
- [ ] 光区轴纯逻辑模块有单测覆盖：比例定位、未覆盖区间、重叠判定、单颗光区、整条覆盖、零光区
- [ ] 类型检查、全部单元测试、渲染层回归脚本全部干净
