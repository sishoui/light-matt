# 07: 进阶档 · 效果面板

## Parent

## What to build

进阶档的第三层：效果面板。

**效果类型在最上**，四个等宽按钮：静态 / 呼吸 / 彩虹 / 流光。

**参数区按类型整体替换**：

- 静态：色相、饱和度、亮度
- 呼吸：色相、饱和度、亮度、周期、最低亮、波形（正弦 / 三角 / 锯齿 / 方波）
- 彩虹：周期、跨度、方向（正转 / 反转）
- 流光：色相、饱和度、亮度、周期、尾长、方向

用户永远看不到当前类型用不上的旋钮。切换类型时保留颜色，其余参数按新类型的语义重置。

**颜色一律用色相 / 饱和度滑块**，色相滑轨显示彩虹渐变，右侧显示当前数值与单位（色相带度号，饱和度与亮度带百分号），数值用等宽数字。拖动过程中只更新本地草稿与预览，不逐帧写设备。

**底部只保留一个主按钮「应用并播放」**：有未写入的改动时自动先写入再播放；写入失败时在按钮下方就地显示原因，不要弹窗打断。

这一票还要在进阶档显示两条必须让用户知道的事实：方案内容只存在本机（设备只回步骤数与是否启用，内容读不回来），以及换机或清缓存后需要重新编排。

## Acceptance criteria

- [ ] 效果类型行在最上，切换类型后参数区整体替换，不出现当前类型用不上的旋钮
- [ ] 静态只有三项（色相、饱和度、亮度），呼吸/彩虹/流光各多出自己的参数
- [ ] 色相滑块能从零到三百六十度取任意颜色，滑轨呈现彩虹渐变
- [ ] 饱和度与亮度滑块工作正常，右侧数值与单位随拖动更新
- [ ] 切换效果类型时颜色保留，其余参数按新类型默认值重置
- [ ] 拖动滑块过程中不逐帧写设备，松手后才提交
- [ ] 底部只有一个「应用并播放」按钮，有改动时自动先写入再播放
- [ ] 写入失败时在按钮下方就地显示原因，不弹模态框
- [ ] 进阶档明确告知：内容仅存在本机，换机或清缓存后需要重新编排
- [ ] 方案为空时显示引导而不是一片空白
- [ ] 界面上不出现协议词（毫秒 / 段 / 阶段 / 剧本 / 下发 / 激活 / blend / 第几层）
- [ ] 灯效编辑回归脚本覆盖：切类型后参数区整体替换、色相能取到任意值、应用并播放真的改了设备
- [ ] 类型检查、全部单元测试、渲染层回归脚本全部干净
