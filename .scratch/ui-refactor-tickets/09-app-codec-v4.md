# 09: 小程序编解码接 v4

## Parent

#60

## What to build

小程序侧的编解码接上 v4，让灯组页里的亮度滑块真正下发到设备。

层编解码按九字节改完，装配光区时必须保证空层亮度为零、非空层亮度落在一到一百（零也合法），所有构造光区的路径共用同一处实现。灯组页上「固件更新后可用」的临时标记去掉，滑块改完即真实生效。

真机验收：同一条灯组上划出两个光区，把其中一个设到明显更暗的档位，肉眼确认两段明暗不同；再验证呼吸结构下谷底确实等于光区亮度乘以最低亮百分比。

## Acceptance criteria

- [ ] 小程序发出的段与方案帧都是九字节层编码，字节与跨端向量逐字节一致
- [ ] 灯组页的亮度滑块改完立即下发，且真的改变设备上那一段的亮度
- [ ] 同一条灯组上两个不同亮度档的光区肉眼可分辨
- [ ] 呼吸结构下谷底等于光区亮度乘以最低亮百分比
- [ ] 空层编码的亮度为零，不会被设备拒绝
- [ ] 「固件更新后可用」的临时标记已从界面移除
- [ ] 光区装配的约束有单测覆盖：空层亮度为零、超范围亮度被拦下
- [ ] 方案草稿按灯组切片替换的既有测试补上亮度断言，仍保证只替换当前灯组
- [ ] 真机验收结果记录到验收文档，含明暗对比的实测结论
- [ ] 类型检查、全部单元测试、真机端到端测试全部干净
