> 规格父票：GitHub #85。实现票：#86–#89。

## Problem Statement

小程序在四个版本迭代后功能已经齐了，但用户拿起来用时会撞上这些问题：

**主题只改了一半。** 在「我的」页切浅色/深色，只有这一页变了；回到首页、进入设备页，颜色还是旧的那套，自建的导航栏和 tabBar 也不跟着换。用户会以为切换没生效。

**删掉的设备找不回来。** 在「我的」页删除一台设备后再去扫描，永远搜不到它。删除只清了本机登记表，连接没断；而固件一旦连上就停止广播，所以扫描里根本没有这台设备。更糟的是后台重连监控会拿旧的「上次设备」记录在切页时自动连回去，把刚删掉的设备重新写回列表。演示设备也一样，删了下次启动又回来。

**大卡上的电源键像坏的。** 点下去什么都没发生——要么这台设备只有云端记录、没有本机连接标识，要么在连接中的几秒里没有任何提示，要么连上了但状态还没到。三种情况都是静默返回。

**选灯效要等两秒。** 点一张效果卡，选中高亮过一两秒才定下来。高亮本来点下去就变，但写设备完成后的一次读回会按设备真实状态重算选中项，一个迟到的读回就把刚选的覆盖回去；写期间再点卡片则被直接丢弃，毫无反馈。

**发现页一点就跳走。** 扫描到设备点一下直接连接并离开页面，没有机会设名称和封面。用户只能事后再去设备信息页改名，封面要在首页卡片上点一个「封面」按钮。

**灯效名像色卡。** 「暖白常亮 / 冷蓝氛围 / 紫色氛围 / 爆闪白 / 心跳暖红 / 熄灭黑」——用户是来选灯效的，不是来选颜色的。而且简单档是九张带色块的卡，一屏塞不下。

**改一个灯组串到别的灯组。** 在灯组 A 的进阶档里设好效果，灯组 B 也跟着变。因为方案是设备级的，下发时覆盖了设备上所有灯组，而草稿里并没有灯组 B 的内容，于是它退回成单色。

**播一段就停。** 点「应用并播放」后灯组跑完一遍就定格在最后一帧。设备上的循环标志默认关，而界面上根本没有循环开关。

**光区这个词和这套交互都不合直觉。** 用户想要的是「背景层 + 特效层」两类：底下铺一层常亮或呼吸，上面叠一层流星或随机闪烁。现在只有一个「效果」加一个「叠加效果」，还要选「覆盖/相乘/相加」。

## Solution

### 主题：灰蓝

整套主题色从橙换成**雾蓝**（浅色 `#6B8CAE`，深色 `#8FA9C4`），背景与卡片走冷灰调。所有页面、导航栏、tabBar、滑块、开关、进度条统一换色，橙色不留残留。切完主题回到任意页面、任意 tab，三处同时换色，不需要重进页面。

### 设备管理

删除设备 = 断开连接 + 清本机登记 + 清上次设备 + 清封面 + 清草稿。删完能重新扫描到并重新添加。演示设备删了就是删了，不会自己回来。

首页大卡电源键：仅云端记录时给说明、连接中显示进度、连上后给反馈，不再静默。

长按任意设备卡（大卡或小图）从底部弹出菜单：修改名称 / 更换封面 / 移除封面 / 断开连接 / 删除设备。大卡上原有的「封面」按钮去掉。

### 首页

右上角「发现」文字换成加号图标，点开下拉菜单（本轮里面只有「添加设备」）。标题下加一个灰底圆角搜索框，按名称过滤；不搜索时是「大卡 + 小图」，搜索时整页变成一列设备卡。大卡上的亮度从只读的条改成可拖拽的滑条，拖完就真的改设备亮度。

### 发现页

重做成清单式：灰底搜索条、分组标题、每行设备（封面缩略图 + 名称 + 信号条）、底部重新扫描。点任意一行不再是直接连接，而是从底部弹出表单填名称与封面，再点「添加并连接」。

### 设备页

去掉「已连接」那一整条状态栏，连接状态收进标题副标题（点副标题可重连）。右上角菜单换成三个点，里面只剩设备信息与断开连接。

灯组卡片从两列改成一列：左边封面、中间名称与灯珠数、右边开关。灯组可以自定义名称和封面，没设置时显示默认名称与占位图。长按同样弹出底部菜单。

### 灯组页

方案固定三套，去掉新增和删除，方案按钮移到标题右侧用圆形数字表示，选中高亮。

灯珠数不再是一个独立滑块区块，而是标题右侧一个可长按的胶囊（「64 颗」）；长按弹出圆形拨盘，转动调整、松手下发。

简单档不再是一堆色块卡，而是一行一个灯效：左边名称，右边当前灯效名，点击从底部弹出滚轮选择。

「应用并播放」按钮去掉，改成任何改动都立即生效。

分区弹窗去掉取消按钮（点空白就关），去掉「改范围」按钮（再点一次或长按进入编辑），新增预览按钮（按分区颜色画出每一颗灯珠）。

「光区」改名为**分区**。

### 进阶页

时间轴标题放大，步骤数与总秒数变成副标题；去掉删步骤按钮，加步骤移到标题右侧；时间轴不再包在卡片里。

选中一个步骤，下方出现气泡卡片（箭头指向选中块正中），里面是步骤名、时长滑轴、分区列表。

灯效分成两个层：背景层放常亮、呼吸、彩虹这类全局铺底的；特效层放流星、随机闪烁这类流动的。特效有颜色时会盖住背景，没颜色时透出背景——这对应协议里的「相加」与「覆盖」两种混合，界面只保留这两个选项。

最终灯效清单八个：空、常亮、呼吸、彩虹、流星、爆闪、心跳、随机闪烁。名字里不再出现颜色。

### 协议与固件

三处扩展，协议版本号保持 v4 不变：流星可调**密度**（同时几个流星头）与**拖尾是否衰减**；新增**随机闪烁**类型；循环从「开/关」扩成**不循环 / 全部循环 / 最后一步循环**三档。

同时修掉「改一个灯组串到别的灯组」：下发方案前补齐其它灯组在草稿里的切片，不再让它们退回单色。

## User Stories

### 主题

1. 作为用户，我想在「我的」页切到深色后回首页时页面和导航栏都已经是深色，这样我不会以为切换失败。
2. 作为用户，我想进入设备页时它也是当前主题，这样页面之间不会一深一浅。
3. 作为用户，我想底部 tabBar 的颜色跟着主题走，这样它在深色下不会突然变成一块亮条。
4. 作为用户，我想所有滑块、开关、按钮都用同一个主题色，这样界面看起来是一个整体。
5. 作为用户，我想深色下没有白底白字或黑底黑字，这样我在夜里能看清每一处文字。
6. 作为用户，我想主题色是灰蓝而不是橙，这样它看起来更安静、更配灯光的颜色。

### 设备管理

7. 作为用户，我想删除一台设备后它从列表里立刻消失，这样我不会对着一个已经删掉的条目发呆。
8. 作为用户，我想删除后重新扫描能再次找到这台设备，这样我删错了还能加回来。
9. 作为用户，我想删除当前正连着的设备时它真的断开，这样我不会以为删除只是换了个名字。
10. 作为用户，我想删掉的演示设备不会下次启动又冒出来，这样「删除」是可信的。
11. 作为用户，我想点仅云端记录的设备的电源键时看到一句说明，而不是点了没反应。
12. 作为用户，我想点未连接设备的电源键时看到「正在连接」，这样我知道它在干活。
13. 作为用户，我想连接失败时看到原因，这样我知道该重试还是该检查设备。
14. 作为用户，我想长按大卡弹出菜单，这样我不用为了改个名字进三层页面。
15. 作为用户，我想长按小图也能弹出同一个菜单，这样操作一致。
16. 作为用户，我想在长按菜单里改设备名称，这样我能把 `Lumen-9B77` 改成「客厅灯带」。
17. 作为用户，我想在长按菜单里换封面或移除封面，这样我不用在大卡上找一个按钮。
18. 作为用户，我想在长按菜单里直接断开或删除，这样常用操作都在一处。

### 首页

19. 作为用户，我想首页右上角是加号而不是「发现」两个字，这样添加设备这个动作更直白。
20. 作为用户，我想点加号展开一个下拉菜单，这样以后加功能不会挤满标题栏。
21. 作为用户，我想在首页搜索框里按名称找设备，这样设备多了也不用一条条翻。
22. 作为用户，我想搜索不区分大小写，这样输 `lumen` 也能匹配 `Lumen-9B77`。
23. 作为用户，我想搜不到时看到一句空态提示，这样我知道是没有匹配而不是页面卡了。
24. 作为用户，我想点搜索结果后大卡切到那台设备并清空搜索，这样选完就回到正常视图。
25. 作为用户，我想搜索只切换显示而不发起连接，这样我浏览设备时不会无谓地断开当前连接。
26. 作为用户，我想拖大卡上的亮度条就能改亮度，这样我不用进设备页。
27. 作为用户，我想拖亮度条时数字跟着动、松手才下发，这样设备不会被连续命令刷屏。

### 发现页

28. 作为用户，我想发现页有一个搜索框，这样设备多时可以按名字找。
29. 作为用户，我想每行能看到封面、名称和信号强弱，这样我能判断该连哪一台。
30. 作为用户，我想点一行不是直接连上而是弹出表单，这样我有机会先起名字。
31. 作为用户，我想表单里预填广播名，这样我不用从零开始打。
32. 作为用户，我想表单里可以选封面，这样加进来的设备卡片不是一片空白。
33. 作为用户，我想点「添加并连接」后设备出现在首页并显示我起的名字，这样添加这一步是完整的。
34. 作为用户，我想对已添加过的设备再点一次时看到「已添加过」的说明并预填现有资料，这样我不会重复添加或覆盖掉原来的名字。
35. 作为用户，我想点遮罩就关掉表单，这样我改变主意时不用找关闭按钮。
36. 作为用户，我想关掉表单后扫描还在继续，这样我不会白等一轮。

### 设备页

37. 作为用户，我想设备页顶部直接显示连接状态，这样我不用先读一条单独的状态栏。
38. 作为用户，我想点标题下的状态文字能重连，这样断线时我不用到处找重试。
39. 作为用户，我想右上角是三个点而不是「菜单」两个字，这样它更像一个入口。
40. 作为用户，我想下拉里只有设备信息和断开连接，这样不会和首页的添加设备重复。
41. 作为用户，我想灯组卡片一列排下来，这样每张卡有位置放封面和名字。
42. 作为用户，我想灯组卡片左边是封面，这样不同灯组一眼能区分。
43. 作为用户，我想没有自定义封面的灯组显示占位图，这样卡片不会是一块纯色。
44. 作为用户，我想给灯组改名字，这样我能把「灯组 2」改成「书桌」。
45. 作为用户，我想给灯组换封面，这样我能按实际位置区分它们。
46. 作为用户，我想灯组名字在设备页、灯组页、设备信息页三处一致，这样我不会看到一个地方一个名字。

### 灯组页：方案

47. 作为用户，我想只看到三个方案，这样我不会被一堆空位搞糊涂。
48. 作为用户，我想方案按钮是圆形数字排在标题右边，这样切换方案不用往下翻。
49. 作为用户，我想选中的方案高亮，这样我知道现在在编哪一套。
50. 作为用户，我想点一个有内容的方案就立即生效，这样我不用再点一次「应用」。
51. 作为用户，我想点一个空方案时画面不变，这样我不会把设备刷成一片黑。
52. 作为用户，我想找不到新增/删除方案的入口，这样三套就是三套，不会越想越乱。

### 灯组页：灯珠数与分区

53. 作为用户，我想在标题右边看到当前灯组的灯珠数，这样我不用找滑块。
54. 作为用户，我想长按灯珠数弹出圆盘，这样调数量像调旋钮一样自然。
55. 作为用户，我想转圆盘时中间的数字实时跟着变，这样我知道拖到多少了。
56. 作为用户，我想松手才真正下发，这样设备不会被连续命令刷屏。
57. 作为用户，我想缩小灯珠数会裁掉已有分区时先被问一句，这样我不会莫名其妙丢编排。
58. 作为用户，我想分区这个名字比「光区」好懂，这样我知道它指的是灯珠的一段。
59. 作为用户，我想选中一个分区时灯珠有边框高亮，这样我知道选中了哪一段。
60. 作为用户，我想选中分区的终点时那一颗背景高亮，这样我分得清起点和终点。
61. 作为用户，我想点空白处就关掉分区弹窗，这样我不用去找取消按钮。
62. 作为用户，我想再点一次或长按就进入改范围，这样不用先选再点一个「改范围」。
63. 作为用户，我想点预览能看到整组每一颗灯珠按分区颜色画出来，这样我一眼确认分配对不对。

### 灯组页：灯效与立即生效

64. 作为用户，我想灯效是一行一个、左边名称右边当前值，这样我不用在色块里找。
65. 作为用户，我想点一行从底部弹出滚轮选灯效，这样选择像系统选择器一样熟悉。
66. 作为用户，我想灯效名字不带颜色，这样我是按效果选而不是按颜色选。
67. 作为用户，我想只有「彩虹」这个名字里有颜色，因为那本来就是灯效本身。
68. 作为用户，我想没有「应用并播放」按钮，改完就是生效，这样少一步操作。
69. 作为用户，我想改完很快看到灯组真的变了，这样我能边调边看。
70. 作为用户，我想写入失败时看到一行原因，这样我知道这次没生效。
71. 作为用户，我想简单档和进阶档的参数控件长得一样，这样我不用学两套。

### 进阶页：时间轴

72. 作为用户，我想时间轴标题更大，这样它是这一页的主角。
73. 作为用户，我想步骤数与总秒数在标题下面当副标题，这样我不占额外空间就知道全貌。
74. 作为用户，我想加步骤的按钮在时间轴标题右边，这样它就在该在的地方。
75. 作为用户，我想没有删步骤按钮，这样我不会误删。
76. 作为用户，我想时间轴不包在卡片里，这样它看起来是页面结构而不是一个组件。
77. 作为用户，我想选中步骤后下方出现气泡卡片，这样编辑当前步骤不用滚到别处。
78. 作为用户，我想气泡的箭头对着选中的块中间，这样我知道它属于哪一步。
79. 作为用户，我想气泡里第一行是步骤名，这样我能给每一步起个名字。
80. 作为用户，我想步骤名默认是「第 N 步」，这样我不改也知道这是第几步。
81. 作为用户，我想气泡副标题显示这一步多长、有几个分区，这样我不用自己去数。
82. 作为用户，我想气泡里有时长滑轴，这样调时长就在当前步骤旁边。

### 进阶页：两层与灯效

83. 作为用户，我想每个分区能分别配背景层和特效层，这样我能「先铺一层呼吸，上面再跑流星」。
84. 作为用户，我想背景层放常亮、呼吸、彩虹这类铺底的，这样我知道该往哪层放。
85. 作为用户，我想特效层放流星、随机闪烁这类流动的，这样界面分组符合直觉。
86. 作为用户，我想任何灯效在任一层都能选，这样我想「把彩虹当特效叠上去」也可以。
87. 作为用户，我想背景层可以选「空」，这样我能只留特效层。
88. 作为用户，我想特效有颜色时盖住背景、没颜色时透出背景，这样叠加的观感符合直觉。
89. 作为用户，我想混合方式只有「相加」和「覆盖」两个，这样我不用理解「相乘」。
90. 作为用户，我想界面里没有「叠加效果」这一整块，这样两层本身就是叠加，不用再套一层概念。
91. 作为用户，我想界面里没有「熄灭」这个词，不亮就是「空」。
92. 作为用户，我想流星能调拖尾长短，这样我能做短促的流星也能做长尾。
93. 作为用户，我想流星能调密度（同时几个流星头），这样我能做单颗也能做一串。
94. 作为用户，我想流星能选拖尾是否衰减，这样我能做渐隐的尾巴也能做实色块尾巴。

96. 作为用户，我想循环有三档：不循环、全部循环、最后一步循环，这样我不用为了「停在最后一步」去凑时长。
97. 作为用户，我想循环设置放在时间轴标题右边，这样它是这一套方案的整体设置。

### 观感与诚实

98. 作为用户，我想在灯组 A 上编排时灯组 B 的画面不动，这样多灯组设备上我敢放手编。
99. 作为用户，我想改动灯效后选中项立刻定下来，不会过两秒又被改回去。
100. 作为用户，我想快速连点不同灯效时每一次都执行，这样我不会疑惑「我明明点了」。
101. 作为用户，我想界面上的每次点击都有结果，哪怕是失败也有说明，这样我不会怀疑是不是没点上。
102. 作为开发者，我想烧录新固件后设备配置回默认值这件事被写明，这样用户不会以为配置丢了。

## Implementation Decisions

### 主题

- 主题变量集中在全局样式的 `.page` 上，三套定义（浅色默认、深色媒体查询、手动覆盖 light/dark）必须同步改，改一处漏两处就会出现某个主题下的错色。
- 主题色具体值：浅色 `#6B8CAE`、深色 `#8FA9C4`；背景与卡片走冷灰（浅色背景 `#F2F4F7`、深色背景 `#0F1419`）。
- 滑块组件的激活色**不能**从样式变量读，必须由页面数据传入颜色值。这是本轮最容易漏的一处：漏了就是「整体换了，滑块还是橙的」。
- 主题读取统一走一个函数（读存储 → 返回 class），页面在**显示时**重新读。tab 页只加载一次，靠加载时缓存的值永远不会更新。
- 自建导航栏是独立组件，样式隔离，页面根节点的 class 传不进去，必须由组件自己在**页面显示**时重算一次。tabBar 同理。
- 页面级样式里禁止出现写死的十六进制颜色；这条已有单测守着，新代码要让它继续通过。

### 设备删除

- 删除是**一组动作**，缺任何一步都会留下「删了但还在」的痕迹：断开连接、清登记表、清最近记录、清上次设备、清封面文件、清方案草稿。
- 「断开连接」是必须的：固件连上后停止广播，只要还连着，扫描就永远看不到这台设备。这是「删了搜不到」的直接原因。
- 「清上次设备」是必须的：重连监控在页面显示时会拿这条记录自动重连，并把它写回最近记录。
- 演示设备要记住「用户显式删除过」，否则恢复逻辑会在下次启动重新播种。

### 首页与电源键

- 电源键的三条静默返回都要补反馈：无本机连接标识、连接中、连上后状态未到。
- 大卡的长按手势让给底部菜单，不再承担「清除封面」。
- 亮度滑条拖动期间只更新本地显示，松手后做一次防抖再下发，避免拖一次发几十帧。

### 发现与添加

- 扫描结果点击改为弹出表单，字段是名称与封面；名称落到设备备注（并走既有云端同步旁路），封面落到封面存储。
- 表单用页面内的视图实现，不用系统动作面板：需要输入框与相册选图。
- 已添加过的设备在表单里预填现有资料并注明「已添加过」，避免覆盖用户起过的名字。

### 搜索

- 只匹配名称（备注名优先、其次广播名），不匹配设备标识。匹配不区分大小写、去首尾空白。
- 搜索为空时保持「大卡 + 小图」；有关键字时切换为一列结果，点结果只做选中并清空搜索，不发起连接。

### 灯组与分区

- 灯组名称与封面是本机数据，单独一个存储键，键由设备稳定标识与灯组号组成。默认名「灯组 N」。
- 占位封面按灯组号对现有素材取模固定分配，保证同一灯组每次都一样。
- 「光区」统一改叫「分区」，包括文案、变量名注释与验收项。

### 方案三套

- 协议层仍有四个方案槽位，界面只用前三个。第四个槽位的旧草稿直接清掉，不做兼容迁移（用户明确：当前测试阶段不需要兼容）。
- 方案是**设备级**的：一套方案覆盖所有灯组，灯组只是编辑视角。界面只编辑「当前灯组 × 当前步骤」那一片，其它灯组的切片原样保留。
- 点方案时：有内容就立即启用并播放；没有内容不写设备，避免把设备刷成空白。

### 立即生效

- 任何改动做一次防抖后依次执行：停播（若在播放）→ 写当前灯组当前步骤的实时光区 → 静默下发整份方案 → 恢复播放。
- 停播是必须的第一步：设备在播放方案时按方案渲染，写进去的实时光区看不见。这是硬件事实，界面不要假装能实时预览。

### 灯珠数圆盘

- 长按标题右侧的灯珠数胶囊打开底部圆盘，范围 1–100，每 10 颗一条长刻度。
- 拖动只改本地显示，松手下发。缩小到会裁掉已有分区时先确认。

### 进阶页两层

- 每个分区两个层槽位：背景层与特效层。
- 混合方式从三种收窄到两种：相加与覆盖。移除相乘（界面上说不清）。原来的「叠加效果」整块删除——两层本身就是叠加。
- 背景层允许选「空」。协议要求每段的背景层必须是真实灯效，因此「空」在编码上写成既有的「熄灭」类型配合相加，输出等价于不贡献。界面上不出现「熄灭」这个词。

### 灯效清单

- 八个：空、常亮、呼吸、彩虹、流星、爆闪、心跳、随机闪烁。
- 名字里不出现颜色，只有「彩虹」例外（它本身就是彩色的）。
- 「脉冲」并入心跳，用「单/双脉冲」开关表达。

### 协议扩展

- 协议版本号保持 v4，采用原地扩展（与之前新增清空方案命令同一先例）。
- 流星的密度与拖尾是否衰减都放进已有的标志位，不新增字段。
- 随机闪烁作为一种新类型，密度复用该类型原本空闲的参数位。
- 循环字节从布尔扩成三值：不循环 / 全部循环 / 最后一步循环。旧固件收到非法值安全拒绝，不会误改任何东西。
- 「最后一步循环」在设备上的语义是：前 N-1 步各播一次，最后一步原地重播。

### 修复跨灯组串扰

- 下发方案前，从设备读回其它灯组的现有分区并补进草稿，使整份方案里每个灯组都有内容；否则固件会让未覆盖的灯组退回基准单色。

## Testing Decisions

### 什么算好测试

只测外部行为：给定输入（草稿、手势、字节流、页面状态、存储内容），断言可观察的输出（新的草稿、帧字节、视图模型、页面数据、提示文案）。不测私有字段，不测视图结构细节，不测调用顺序。

### 复用现有测试缝（不新建层）

| 缝 | 本轮新增覆盖 |
|---|---|
| 主题 | 三种主题取值到 class 的映射；页面在**显示**时读到最新值（而不是加载时的缓存值）；导航栏与 tabBar 的组件级重算 |
| 设备登记 / 最近记录 / 上次设备 / 封面 / 草稿 | 删除是一次性清干净：六处存储全部为空；保留「显式删除过」标记 |
| 扫描过滤 | 删除后设备仍能被扫描到（过滤逻辑不因删除而改变） |
| 首页视图 | 搜索匹配（名称优先、忽略大小写、不匹配标识）、无匹配时为空、选中逻辑 |
| 设备列表视图 | 灯组元数据默认名与占位封面分配 |
| 效果面板 | 八个灯效的参数键、两层槽位、混合方式只有两种、背景层「空」的编码 |
| 简单档 / 快速效果 | 一行式列表的八个条目、按名称展示 |
| 方案槽管理 | 固定三套、空方案判定、删除槽位四的清理 |
| 命令构造与编解码 | 流星密度与拖尾标志位、随机闪烁新类型、循环三值、旧值拒绝 |
| 固件 host 单测 | 流星的多个头、拖尾不衰减、随机闪烁的确定性与密度、最后一步循环的推进、循环非法值拒绝 |
| 计划下发 | 补齐其它灯组切片后不再产生空切片；只改当前灯组时其它灯组切片不变 |

### 渲染层（模拟器回归）

在现有脚本上补这些「只有渲染层能发现」的检查：切主题后导航栏、tabBar、页面三处同时换色；长按设备卡弹出菜单且各项可点；发现页点结果弹出表单而不是跳转；首页搜索过滤生效、点结果清空搜索；灯组卡片一列布局且长按弹出菜单；方案恰好三个、没有新增删除入口；没有「应用并播放」按钮；分区预览条画出每一颗灯珠；「光区」字样在界面上完全消失。

### 页面与配置契约

沿用现有契约测试：新页面必须出现在页面列表、每个页面加载时显式初始化全部私有字段、相对导入不能指向目录。

## Out of Scope

- 提高动画帧率（保持 20fps；爆闪上限仍是 10Hz）。
- 改蓝牙广播名（固件没有改名命令，名称只存本机/云端）。
- 云端同步方案草稿。
- 兼容旧版第四个方案槽位的草稿（明确直接删）。
- 跨设备迁移灯组名称与封面。
- 主题新增第三套配色（只做浅色与深色两套，外加跟随系统）。

## Further Notes

### 三个老陷阱

1. 相对导入不能指向目录，小程序的模块解析不认目录 index，在启动链上会整个白屏，`tsc` 与单测都发现不了。
2. 页面对象字面量上的私有字段运行时是未定义值，必须在页面加载时显式初始化；漏掉会中断整页事件绑定，表现为「点什么都没反应」。
3. 写整组前必须先清掉该组其它分区，否则同带不重叠的校验会把写入拒绝，用户点了卡片却毫无变化。

### 本轮新增的四个陷阱

4. 滑块组件的激活色不接受样式变量，必须由页面数据传值。漏了就是「换了主题，滑块还是橙的」。
5. 删除设备必须断开连接。不断开，固件就不重新广播，设备彻底搜不到——这是「删了搜不到」的根因。
6. 方案是设备级的。任何「只改当前灯组」的下发，都要保证其它灯组的切片不被清空。
7. 选中状态必须在写入期间保持权威。写入后的读回会按设备真实状态重算选中项，迟到的读回会把用户刚做的选择覆盖回去。
