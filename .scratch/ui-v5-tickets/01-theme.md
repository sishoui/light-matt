## Parent

#85（规格：小程序 UI / 交互第五轮）

## What to build

把整套主题色从橙换成**雾蓝**，并让主题切换真正全局生效。

颜色：浅色 `--accent #6B8CAE`，深色 `#8FA9C4`；配套背景与卡片走冷灰（浅色 `--bg #F2F4F7`，深色 `--bg #0F1419`）。同步 `--accent-soft`、`--blue`、导航栏的 `--nav-*`、tabBar 的 `--tab-*`。页面样式里写死的橙色一律清掉。

滑块组件的激活色读不到样式变量，必须由页面数据传进去——这是最容易漏的一处：漏了就是「整体换了，滑块还是橙的」。所有用到滑块、开关、进度条的地方都要收口到同一个颜色来源。

主题切换要在**页面显示时**重新读取，而不是加载时缓存。当前有三个断点：首页拿着加载时的旧值比较、设备页的显示回调里完全没有主题刷新、自绘导航栏只在挂载时读一次。tabBar 也只靠「我的」页推送。四处一起修，切完主题回到任意页面、任意 tab，页面本体、导航栏、tabBar 三处同时换色。

## Acceptance criteria

- [ ] 在「我的」页切浅色 / 深色，回到首页，页面与导航栏、tabBar 同时换色
- [ ] 进入设备页、灯组页、发现页、设备信息页，全部是当前主题
- [ ] 全仓没有 `#ff9500` 作为主题色残留（滑块开关按钮进度条统一走新主题色）
- [ ] 浅色与深色下所有页面没有白底白字 / 深底深字
- [ ] 页面样式里没有新增写死的十六进制颜色（已有单测继续通过）
- [ ] `npx vitest run`、`npx tsc --noEmit` 干净
- [ ] `node .auto/verify-redesign.mjs` 通过
- [ ] 新增单测：页面在**显示**时读到最新主题值；导航栏与 tabBar 的组件级重算
