## Parent

#85（规格：小程序 UI / 交互第五轮）

## What to build

首页四个改动，都建立在 #87 的底部弹层与名称/封面写入路径上。

**右上角加号。** 把「发现」文字按钮换成加号图标，点开一个下拉菜单，本轮里面只有「添加设备」一项。结构上留出后续加项的位置。

**搜索框。** 标题下一个灰底圆角搜索框，按名称过滤（备注名优先、其次广播名，不区分大小写，不匹配设备标识）。搜索为空时保持「大卡 + 小图」；有关键字时整页变成一列设备卡。点结果只做「选中为大卡」并清空搜索，**不发起连接**——延续「浏览不等于操作」的既有契约。无匹配时给空态文案。

**大卡亮度可拖。** 现在的亮度只是一条只读的百分比条。改成可拖拽滑条，拖动中只更新本地显示，松手后做一次防抖再下发。设备未连接时不显示滑条。

**长按弹层。** 长按大卡或小图从底部弹出同一个菜单：修改名称 / 更换封面 / 移除封面 / 断开连接 / 删除设备。大卡上原有的「封面」按钮去掉，长按也不再承担「清除封面」（手势冲突）。
