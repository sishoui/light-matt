## What to build

**设备页精简。** 删掉「已连接」那一整条状态栏，连接状态收进标题副标题（未连接 / 连接中 / 已连接·灯光打开 / 已连接·灯光关闭 / 连接失败），点副标题可重连。右上角「菜单」文字换成三个点图标，下拉里只剩设备信息与断开连接（「添加设备」已经挪到首页）。

**灯组卡片。** 从两列改成一列：左边封面、中间名称与灯珠数、右边灯组开关。灯组可以自定义名称和封面，没设置时显示默认名「灯组 N」与占位图（按灯组号对现有素材取模固定分配，保证同一灯组每次都一样）。长按卡片从底部弹出菜单：修改名称 / 更换封面。

**新存储键。** 灯组名称与封面是本机数据，单独一个键，由设备稳定标识与灯组号组成。灯组名要在设备页卡片、灯组页标题、设备信息页三处读同一个来源。
