## Parent

#85（规格：小程序 UI / 交互第五轮）

## What to build

简单档整块换掉，并让编辑真正立即生效。

**灯效列表改成一行式。** 不再是九张带色块的成品卡，而是一行一个灯效：左边名称，右边当前灯效名。点击从底部弹出**滚轮选择器**。灯效名字不带颜色（只有「彩虹」例外，它本身就是彩色的）——用户是来选效果的，不是来选颜色的。

**参数区与进阶档一致。** 同一套控件、同样的样式，色相用色环色带。不要把简单档做成另一套平行的控件。

**去掉「应用并播放」。** 任何改动做一次防抖后依次执行：停播（若在播放）→ 写当前灯组当前步骤的实时光区 → 静默下发整份方案 → 恢复播放。停播是必须的第一步：设备在播放方案时按方案渲染，写进去的实时光区看不见。这是硬件事实，界面不要假装能实时预览。写入失败在页面顶部一行说明，不弹模态。

**空方案不写设备。** 避免把一个空草稿刷到设备上。

- [ ] 灯效名称里没有颜色词（「彩虹」除外）
- [ ] 简单档与进阶档的参数控件外观一致
