## Parent

#85（规格：小程序 UI / 交互第五轮）

## What to build

把「光区」这个词和它那一组交互整个换成「分区」。

**改名。** 全页面文案统一为「分区」，包括提示语、确认框、空态文案。

**选中态的视觉。** 选中一个分区时，属于它的灯珠**边框高亮**；选中结束节点后，那一颗**背景高亮**。当前是整块描边，分不清起点终点。

**弹窗简化。** 去掉「取消」按钮——点空白就关。灯珠网格里被别的分区占用的格子保持置灰。

**改范围的手势。** 去掉「改范围」按钮，改成「再点一次或长按」进入编辑。

**预览。** 新增预览按钮：点开一条全宽预览条，按每个分区的颜色画出该组**每一颗灯珠**，让用户一眼确认分配对不对。这是现有分区轴的聚合视图，但要明确标注是预览而不是可编辑的轴。

## Acceptance criteria

- [ ] 界面上找不到「光区」字样，统一是「分区」
- [ ] 选中分区时灯珠边框高亮
- [ ] 选中结束节点后那一颗背景高亮
- [ ] 分区弹窗没有取消按钮，点空白能关
- [ ] 没有「改范围」按钮，再点一次或长按能进入编辑
- [ ] 预览条画出整组每一颗灯珠，颜色与分区一致
- [ ] 预览条只读，点它不会误改分区
- [ ] `npx vitest run`、`npx tsc --noEmit` 干净
- [ ] `node .auto/verify-effect-editor.mjs` 通过并补「术语」「预览条」
- [ ] 新增单测：分区预览的颜色映射（含未覆盖的灯珠）、选中态判定
