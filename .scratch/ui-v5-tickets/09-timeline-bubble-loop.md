## Parent

#85（规格：小程序 UI / 交互第五轮）

## What to build

进阶档的时间轴区域与步骤编辑形态重做，并把循环做成三档。

**时间轴外观。** 标题放大，步骤数与总秒数降为副标题；去掉「删步骤」按钮，「加步骤」移到标题右侧；时间轴不再包在卡片里——它是页面结构，不是组件。

**步骤气泡卡片。** 选中一个步骤后，在它下方出现一张气泡卡片，箭头对准选中块的正中。卡片内容自上而下：第一行步骤名（默认「第 N 步」，长按可改）+ 副标题「1.5 秒 · 2 个分区」；然后这一步的时长滑轴（0.5–30 秒）；然后分区列表（颜色点 + 「0–19 颗」+ 效果摘要），点一行展开该分区的背景层与特效层（两层本身在下一张票里做，这里先把展开位置留好）。原来独立的时长块并入气泡。

**循环三档。** 设置放时间轴标题右侧，一个全局设置不属于某一步：不循环 / 全部循环 / 最后一步循环。「最后一步循环」的语义是前 N-1 步各播一次、最后一步原地重播。协议侧的循环字节扩成三值在 #89 里做；**这张票先把界面与草稿字段落地，循环的实际下发在协议就绪后打开**（未就绪时第三档灰显并说明）。
