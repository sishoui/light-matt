## What to build

把进阶档的「效果 + 叠加效果」改成**背景层 + 特效层**两个平级的层，并把灯效清单换成不带颜色的八个名字。

**两层模型。** 每个分区两个槽位：背景层（常亮、呼吸、彩虹这类铺底的）与特效层（流星、随机闪烁这类流动的）。分组只是排序与提示，任何灯效在任一层都能选。背景层允许选「空」，这样就可以只留特效层。

**混合方式只剩两种。** 相加与覆盖。移除「相乘」——界面上说不清。原有「叠加效果」整块删除：两层本身就是叠加，不需要再套一层概念。

**「空」与「熄灭」。** 协议要求每段的背景层必须是真实灯效，「空」在编码上写成既有的「熄灭」类型配合相加，输出等价于不贡献。界面上不出现「熄灭」这个词。

**灯效清单（八个）：** 空、常亮、呼吸、彩虹、流星、爆闪、心跳、随机闪烁。名字里不出现颜色。「脉冲」并入心跳，用「单/双脉冲」开关表达。

## Acceptance criteria

- [ ] 每个分区能分别配置背景层与特效层
- [ ] 两层都有完整的灯效清单，任何效果在任一层都能选
- [ ] 背景层能选「空」，选后该层不贡献光
- [ ] 混合方式只有「相加 / 覆盖」两项
- [ ] 页面里没有「相乘」
- [ ] 页面里没有「叠加效果」区块
- [ ] 界面里没有「熄灭」这个词
- [ ] 灯效清单恰好八个，名称里没有颜色词（「彩虹」除外）
- [ ] 心跳有单 / 双脉冲开关，没有独立的「脉冲」灯效
- [ ] 两层都能改参数且互不干扰
- [ ] `npx vitest run`、`npx tsc --noEmit` 干净
- [ ] `node .auto/verify-effect-editor.mjs` 通过并补「两层」「八灯效」
- [ ] 新增单测：八个灯效的参数键、背景层「空」的编码、两层独立配置
