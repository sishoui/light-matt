## Parent

#85（规格：小程序 UI / 交互第五轮）

## What to build

这一张动固件与协议，是整轮唯一需要刷新设备的一组。协议版本号**仍是 v4**，采用原地扩展（与此前新增清空方案命令同一先例）。

**流星。** 可调密度（同时有几个流星头，沿整条均分间距）与拖尾是否衰减（衰减 = 现有的指数渐隐；不衰减 = 实色块拖尾，头与尾之间保留一颗的亮暗差以免糊成一片）。两者都放进已有的标志位，不新增字段。多个头在同一帧取最大值合成，不要相加，避免亮度翻倍。

**随机闪烁。** 新增一种类型，密度复用该类型原本空闲的参数位。每颗灯珠按自己的哈希相位独立做亮灭方波，密度控制同时亮着的比例。必须是**确定性**的（同一颗灯珠同一时刻结果一致），不能每帧随机——那会变成白噪声。

**循环三档。** 循环字节从布尔扩成三值：不循环 / 全部循环 / 最后一步循环。设备上「最后一步循环」的语义是前 N-1 步各播一次、最后一步原地重播。旧固件收到非法值安全拒绝，不误改任何东西。

文档、两代测试向量与小程序编解码必须在同一个提交里一起走。

## Acceptance criteria

- [ ] 流星能调出 1/2/3/4 个流星头，间距均分
- [ ] 流星能切换拖尾是否衰减，两种观感明显不同
- [ ] 随机闪烁在密集与稀疏两档下观感不同
- [ ] 随机闪烁是确定性的：同一设备同一时刻反复观看结果一致，不是逐帧白噪声
- [ ] 循环三档在真机上表现正确：不循环停在末帧、全部循环回到第一步、最后一步循环只停在末步重播
- [ ] 旧固件收到新类型或非法循环值回「参数非法」，不误改任何配置
- [ ] 协议文档更新，测试向量重新生成，固件 / 小程序 / 向量校验脚本三端一致
- [ ] 固件 12701 项断言全绿，78 条 v4 向量通过
- [ ] `npx vitest run`、`npx tsc --noEmit` 干净
- [ ] 真机探针补三项新能力的验证
