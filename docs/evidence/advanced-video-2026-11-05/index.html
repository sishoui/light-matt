先说最重要的一件事

当前版本里，进阶档只有「循环三档」会在点下去时真正写给设备。 其余改动（选灯效、划分区、调参数、改时长）点完只写进手机本地草稿，设备毫无反应 —— 这一点在下面每个步骤的「① 只点击」视频里可以直接看到。

所以每个步骤都录了两段：① 只点击（今天用户点完看到的真实画面）与 ② 点击后应用（调用页面自己的下发逻辑，验证这套编排本身对不对）。

发现的问题

步骤现象视频
点灯效「随机闪烁」与预期不符：背景层应为 随机闪烁 0x07，实际 常亮 0x00查看

根因：utils/control/effect-panel.ts 的 panelLayer() 是一次 switch (type)，但分支里没有 case "flicker"，于是「随机闪烁」落到 default（里面是静态层 {type: STATIC, periodMs: 0, p5: 0, flags: 0}）。同文件的 TYPE_VALUE 与 panelTypeOf() 都认识 flicker → 0x07， SLIDER_KEYS.flicker 也定义了四个滑块 —— 唯独真正生成层的那一处漏了。 defaultParams("flicker") 同样走 default，所以它的周期默认是 0。

为什么测试没拦住：effect-panel.test.ts 断言的是类型清单里有 flicker、滑块表里有它，没有断言 panelLayer("flicker") 产出的 type 是 0x07。这是「测了清单没测映射」的典型缺口。
