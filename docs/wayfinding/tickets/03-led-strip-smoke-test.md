# 03：led_strip 点灯验证（固件骨架）

**类型**：`wayfinder:prototype`（HITL）

## Question

在真实的 ESP32-C3FH4 + WS2812B 上，用 ESP-IDF 的 `led_strip` 组件（RMT backend）能不能稳定点亮 30 灯珠，颜色顺序是不是 GRB，3.3V 数据线有没有阈值问题？

这一票是所有固件工作的地基，也是**风险最大的一票**——它同时暴露三个未知：RMT 配置对不对、颜色通道顺序对不对、3.3V 驱动 5V 灯带的电气边界。先把它单独跑通，后面调 BLE 时就不用怀疑灯带本身。

### 要验证的

1. `espressif/led_strip` 组件拉取成功，`RMT` backend 在 C3 上编译通过
2. 30 灯珠全红 / 全绿 / 全蓝依次点亮，肉眼确认颜色顺序（GRB 假设是否成立）
3. 低亮度（1/255）与中亮度（128/255）的表现，确认 gamma 有没有必要
4. 是否有闪烁、尾部灯珠颜色异常、首个灯珠错色（典型电平/接地问题的症状）
5. **供电能力**：30 灯全白会拉约 1.8A（单灯 60mA 通用值），而开发板 USB 5V 通常限流 500mA-1A。实测全白时是否掉压、是否导致板子重启

### 已知的电气风险（不是「可能」）

研究确认（WS2812B datasheet）：**VIH = 0.7 × VDD**，5V 供电时 VIH = **3.5V**，而 C3 输出高电平约 3.3V。**这是规格不满足，不是余量不足**。表现通常是「多数时候能亮，偶发首灯错色或整条闪烁」。

本票**故意不加电平转换**（开发阶段），目的是先摸清灯带在这块板上到底能不能用。如果症状出现，那就不是继续调代码，而是回到接线说明里标注「必须加 74AHCT125」——这颗器件你画板时一定要留。

接线必备：首灯并 500-1000µF / ≥6.3V 电容，数据线串 300-500Ω 电阻（靠近灯珠一端），**必须共地**。

### 不做

灯效、动画、BLE。只有一个 main 里循环切红绿蓝的裸工程。

## Blocked by

- 【开发环境就绪】——没有工具链什么都烧不进去

## 交付

- `firmware/` 下的最小可烧录工程（临时 main，后续被正式结构替换）
- 一份接线说明：GPIO3 → DIN、5V 供电、**共地**、灯带方向
- 一份实测结论：颜色顺序、亮度表现、有无电平问题

## 验收

- [ ] 30 灯珠全亮，颜色均匀，无尾部衰减
- [ ] 纯红 / 纯绿 / 纯蓝三帧的实际颜色与命令一致（或明确记录需要交换哪两个通道）
- [ ] 连续点亮 5 分钟无闪烁、无重启
- [ ] 全白高亮度实测结果记录在案（是否掉压 / 重启 / 必须限亮度）
- [ ] 接线说明写清共地与电平转换要求
