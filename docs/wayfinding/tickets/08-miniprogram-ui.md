# 08：小程序控制界面

**类型**：`wayfinder:prototype`（HITL，需要你看真机效果）

## Question

一页放完「连接状态 → 开关 → 亮度 → 色环 → 预设色块 + 隐藏日志面板」，在真机的手感和可读性够不够？

这一票是唯一有主观判断成分的票：控件的尺寸、拖动的跟手度、色环的触控精度、日志面板的开关方式。你需要在真机上看过再定。

### 要做的

1. **顶部连接状态条**：未连接 / 扫描中 / 已连接（带设备名），点击可触发扫描/断开
2. **扫描连接弹层**：列出扫到的设备（广播名 + RSSI），点击连接，含错误提示
3. **开关**：独立大按钮，与亮度解耦
4. **亮度滑块**：0-255，拖动实时下发（经节流层）
5. **色环取色器**：HSV 取色，转 RGB 下发
6. **预设色块**：6-8 个（暖白 / 冷白 / 红 / 绿 / 蓝 / 紫 / 橙），点击切色
7. **隐藏日志面板**：连点标题 5 次开启，含时间戳 / 方向 / hex / 解析结果，带暂停 / 清空 / 复制
8. **进前台静默回连**，回连成功后自动同步 UI 状态

### 要观察的（真机）

- 滑块拖动时灯带跟随是否有可感延迟
- 色环在手机小屏上的触控精度
- 低亮度下滑块的可操作区间是否够
- 日志面板在小屏上是否可读

### 不做

不做多页面、不做设备列表页、不做主题、不做动画过渡。

## Blocked by

- 【小程序 BLE 传输层与协议 codec】

## 交付

- `miniprogram/pages/control/` 下的完整页面
- 一份真机截图或录屏 + 你的手感反馈

## 验收

- [ ] 单页内完成「连上 → 开关 → 调光 → 调色 → 预设」全流程，无页面跳转
- [ ] 拖动亮度滑块灯带实时跟随，无可感延迟
- [ ] 色环选色后灯带颜色正确、无偏色
- [ ] 预设色块点击即生效
- [ ] 日志面板能开启、暂停、清空、复制
- [ ] 断线后 UI 显示「未连接」，回连后自动恢复控件状态
